# 业务流程工作台 · Vue 3

Vue 3 + Vite 纯前端项目，无需后端服务或数据库。具体业务内容暂时留空，后续按需求补充。

## 运行

当前电脑已安装 Node.js 和项目依赖。在 PowerShell 中执行：

```powershell
cd "C:\Users\Administrator\Documents\ChatGPT\前端页面"
npm.cmd run dev
```

打开终端显示的地址，通常是 http://127.0.0.1:5173 。端口被占用时，以终端实际输出为准。运行期间保持终端开启，按 `Ctrl+C` 停止。

PowerShell 中使用 `npm.cmd` 可以避免 `npm.ps1` 被脚本执行策略拦截，无需调整系统执行策略。

第一次在其他电脑运行时，先安装 Node.js 22.18 或更新的 LTS 版本，在项目目录执行 `npm.cmd install`，再执行 `npm.cmd run dev`。

## 页面和交互

- 初始流程为：标本、测序、测序数据处理、新抗原选择、mRNA设计、实验。所有页面共用左侧导航；普通步骤单独显示，首页并列添加的实验共用一个“实验”入口。
- 首页是从上到下的圆角流程框，相邻流程以带箭头的直线连接。步骤数量和编号随添加、删除自动更新。
- 点击首页的大步骤进入独立详情页，始终保留左侧侧边栏，页面上方展示该步骤内部的具体流程图，下方展示“内容 / 成本”两列表格。
- 首页编辑名称时，点击框内图标可进入对应详情页；点击输入框可继续修改名称。
- 首页大步骤之间仅显示连接箭头。
- 点击侧边栏的流程名称，进入同一个详情页；也可通过详情页的“返回首页流程图”回到首页。
- 页面通过 Hash 路由导航，支持浏览器前进、后退及直接刷新详情地址，无需服务器配置路由回退。
- 顶部路径支持多层级，如“首页 / 实验 / 湿实验 / 细胞实验”。点击详情页具体流程图中的步骤进入下一级；编辑状态下点击步骤图标进入，名称输入框用于改名。每一级都有自己的流程说明、具体流程和成本表格，可继续添加下一级。
- 顶部任意上级路径都可点击返回；详情页右侧的返回链接回到直接上一级，侧边栏始终返回所属的大流程入口。路径名称自动随步骤名称更新，长路径可横向滚动查看。

### 实验模块

- 首页为“实验”或其并列分支选择“并列添加”时，新增实验继续显示在首页同一层，侧边栏仍只显示一个“实验”格子。选择上方或下方添加时，新增步骤仍在侧边栏单独显示。
- 点击侧边栏“实验”先进入实验列表，较大的卡片从上到下排列为“实验1：名称”“实验2：名称”等，名称直接读取首页实验名称。即使只剩一种实验，也先显示列表。
- 点击卡片进入单个实验的流程页，上方编辑实验内部的具体流程，下方用长方形框展示“实验总成本：数字”，自动汇总所有流程步骤及更深层步骤的成本。这个流程页不再显示成本明细表格。
- 点击流程图中的步骤进入步骤详情，在该页填写具体内容和“内容 / 成本”两列表格，支持行增删编辑与小计；修改后返回实验页，总成本立即同步更新。各实验数据独立，编辑、保存、更改标记及多层返回导航继续可用。
- 若旧实验表格已有明细，原数据继续保留并计入总成本。在总成本框中选择一个流程步骤，点击“移入此步骤”，可把原表格移动到该步骤，与已有明细合并且只计一次；最后点击顶部“保存更改”。没有流程步骤时可先添加步骤，空白原表格不会显示迁移选项。
- 实验详情的路径为“首页 / 实验 / 实验名称 / …”；点击顶部“实验”或“返回实验列表”可回到列表。编辑状态下也可在列表卡片内修改实验名称，与首页同步，最后统一点击顶部“保存更改”。
- 兼容之前已经添加的并列实验；删除原始实验分支后，其余实验仍保留在同一个列表中。
- 实验列表下方的“总成本”自动合计当前列表中所有小实验的总成本；首页流程图下方的“总成本”自动合计全部大流程及其下级成本明细。实验目录只是导航入口，不额外计费，实验成本在首页只计一次。修改、删除和撤销都会立即更新合计，保存后刷新继续恢复。

## 编辑与保存

点击“编辑内容”后，可修改步骤名称、详情页上方的流程说明、内部具体流程，以及下方表格中的内容和成本。修改名称时侧边栏和内容页标题实时同步。原有说明文字保留为详情页上方的“流程说明”。

### 详情页的具体流程与成本

- 上方“具体流程”是独立流程图，使用右下角添加、删除按钮维护内部步骤，支持上方、下方、并列添加。每个大步骤各自保存自己的具体流程。
- 下方表格只有“内容”“成本”两列，初始三行留空。点击表格的“编辑”填写或修改内容与对应成本；点击“添加”在最下方追加一行。
- 点击表格的“删除”，勾选要移除的行后“确认删除”，会同时移除这一行的内容和成本。即使删除全部行，也可以重新添加。
- 表格下方的“总成本”实时对成本列进行数字求和，空白按 0 处理。支持小数，计算时避免浮点尾差；不预设币种。非数字内容会提示修正并阻止保存，合计暂时只包含有效数值。
- 点击顶部“保存更改”统一保存；刷新详情页、返回首页后重新进入，都会恢复已保存的具体流程与表格。

### 添加与删除步骤

1. 点击首页流程图右下角淡蓝色“添加”按钮。
2. 在任意步骤旁选择“上方添加”“下方添加”或“并列添加”。并列添加会把新步骤与所选步骤放在同一行，上一步通过一条公共线分叉连接它们，结束后再汇合进入下一步。
3. 在新步骤框内填写名称，进入该步骤的详情页填写具体流程与成本表格。
4. 点击顶部“保存更改”，一起保存步骤名称、顺序和具体内容。刷新后仍会恢复。

点击右下角“删除”，再点击要移除的步骤，选择“确认删除”。随后点击“保存更改”持久保存。误删时可点击“撤销删除”恢复最近一个被删步骤及其具体内容；恢复后也需保存。可以删除所有步骤，空流程仍可通过“添加”重新创建第一个步骤。

并列关系与名称、具体内容一起保存。并列步骤均可独立点击、填写内容或删除；普通步骤在侧边栏同步显示，并列实验则共用“实验”入口。对并列步骤再次进行“并列添加”会增加同层分支；对其进行上方或下方添加，则在这一整层前或后插入普通步骤。删除后仅剩一个分支时，画布自动显示为普通纵向连接。窄屏下可在画布内左右滑动查看并列步骤。

步骤名称不能为空，最长 100 字；每个步骤的具体内容最长 20,000 字；最多 100 个步骤。删除、插入不会清空其他步骤的内容。

点击“结束编辑”查看效果，再点击“保存更改”（也支持 `Ctrl+S` / `Command+S`）保存全部流程和步骤。结束编辑本身不会保存。页面切换时未保存的内容保留在本次打开的页面内；刷新、关闭时会提示有未保存的修改。

顶部保存状态带有矩形边框，点击“有未保存的更改”可展开列表，按大流程列出修改涉及的模块。点击列表中的流程名称可进入详情页并滚动到修改位置，流程说明、具体流程框以及表格中改过的内容或成本单元格会在左侧显示蓝色圆点。删除的内部流程和表格行会显示待保存的删除说明；已删除的大流程条目会返回首页查看删除提示。列表与标记以上一次成功保存为基准，改回原值或保存成功后自动清除。

数据通过 localStorage 保存在当前浏览器、当前站点地址下，刷新后恢复。更换浏览器、电脑、访问地址或清除站点数据不会携带原内容。当前实现适合本地查看和修改，不提供不同浏览器之间的自动同步。

新版使用 `business-workflow:v2` 存储步骤顺序、名称、并列关系、具体流程和成本表格。旧记录首次读取时会补齐空的具体流程与三行空白表格，已有说明和并列关系继续保留。仍兼容 `business-workflow:v1`，原始旧版记录继续保留。不要手动清除浏览器数据。

## 后续修改位置

- `src/data/workflow.js`：初始流程、动态衔接关系、添加与删除操作及路由定义。
- `src/components/SidebarNavigation.vue`：所有页面共用的侧边栏。
- `src/components/ExperimentCatalog.vue`：并列实验列表，名称与首页同步，点击卡片进入各自详情。
- `src/components/CostTotalCard.vue`：实验列表及首页的总成本显示框。
- `src/data/workflowCosts.js`：统一精确汇总全部大流程、实验及更深层步骤的成本。
- `src/components/WorkflowChart.vue`：首页纵向流程图。
- `src/components/StageContent.vue`：独立详情页，上方具体流程与下方成本表格。
- `src/components/CostTable.vue`：两列表格、行编辑增删与实时合计。
- `src/data/stageDetails.js`：详情初始数据与精确十进制成本求和。
- `src/components/TransitionPage.vue`：相邻流程之间的具体步骤页。
- `src/services/workflowStorage.js`：默认数据及本地读写。
- `src/style.css`：蓝白配色、布局和响应式样式。

日常修改可直接在页面内完成。初始框架定义在 `defaultStages`；已有本地数据会优先显示。

## 构建

```powershell
npm run build
npm run preview
```

部署文件生成到 `dist`，可用于静态网站托管。`npm run preview` 用于本地检查构建结果。

运行 `npm test` 可检查步骤增删、内容保存和旧版数据兼容。
